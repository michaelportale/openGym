When every work set in a session hits the top of the rep range, the weight goes up and the reps return to the bottom of the range. The paper we read supports raising the load or raising the reps. Using a single session as the trigger is our convention, not a finding from that paper.

Our own inference: The one-session trigger is convention. Native suggestions use double progression when neither the exercise nor the routine names a policy. An explicit policy is kept. The shared web default stays linear because this lane does not edit frontend.
